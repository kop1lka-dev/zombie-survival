# 3D Zombie Survival (Мини-проект)

Выживание в темном лесу с зомби, животными, крафтом и исследованием. Игра написана на чистом JavaScript с использованием библиотеки **Three.js**.

## 🎮 Основные механики
* **Выживание**: Следи за здоровьем и воздухом (под водой). Ешь консервы, пей воду, используй бинты.
* **Зомби и животные**: Ночью зомби становятся агрессивнее. Нападай на них, собирай лут (мясо, кожу, ткань).
* **Крафт и постройки**: Создавай оружие (топор, меч, ружьё), инструменты, а также верстак и печь.
* **Исследование**: Исследуй большую карту с рекой, озером и островом. Найди хижины с лутом и поднимись на смотровую вышку.
* **Инвентарь**: Удобная система перетаскивания (Drag & Drop) и быстрый перенос в сундук по **Shift + ЛКМ**.

## 🕹 Управление
* **WASD** — Передвижение
* **Пробел** — Прыжок
* **Shift** — Бег
* **Мышь** — Обзор
* **ЛКМ** — Атака / Добыча ресурсов
* **E** — Взаимодействие (двери, сундуки, верстаки, печи)
* **Tab** — Открыть инвентарь
* **C** — Открыть меню крафта
* **N** — Открыть карту
* **1-6** — Быстрый выбор слота в хотбаре

## 🚀 Как запустить игру

Чтобы игра работала корректно, её нужно запустить через локальный сервер (браузеры блокируют загрузку скриптов из локальных файлов).

### Способ 1: Через VS Code (Рекомендуемый)
1. Скачай и установи [Visual Studio Code](https://code.visualstudio.com/).
2. Установи расширение **Live Server** (автор Ritwick Dey).
3. Открой папку с игрой в VS Code.
4. Нажми правой кнопкой мыши на `index.html` и выбери **Open with Live Server**. Игра откроется в браузере.
